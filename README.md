# Encore

The all-in-one app for piano and guitar creators: track every TikTok/YouTube video, practise with a full 88-key piano, guitar neck, tuner and metronome, get chord charts for any song, and see what to post next. Built by YRB Nova.

- Static site: one `index.html`, no build step, no server, **no running costs**.
- Each user sets up their own profile on first open (name, photo, instruments, socials, colours).
- Data stays on the user's phone (with backup/restore in Profile).
- AI features use each user's **own free Google AI key**, called from their phone, so the app owner never pays for usage.

## Deploy
vercel.com/new → import this repo → Deploy. Nothing to configure.

## Rename
Search `Encore` / `EN<b>CORE</b>` in `index.html` and swap in the new name.
